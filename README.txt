Manger mieux — ajout de produits par code-barres

Après décompression, téléverse index.html et sw.js à la racine du dépôt GitHub Pages puis valide les changements.
Lors du scan ou de la saisie manuelle d’un code-barres, l’application propose Ajouter aux aliments ou Ajouter aux plats.
Pour les plats, le poids du paquet est utilisé si Open Food Facts le fournit ; sinon une base de 100 g est utilisée. Vérifie les données avec l’emballage.
