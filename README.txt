MANGER MIEUX — JOURNAL ALIMENTAIRE

Nouveautés :
- Nouvel onglet « Journal » avec sélection de date.
- Compteurs nutritionnels par jour, semaine, mois et année.
- Ajout d'un plat composé au journal depuis l'onglet Composer.
- Ajout d'une recette au journal depuis l'onglet Recettes.
- Choix du nombre de portions consommées.
- Suppression d'un repas enregistré avec confirmation.
- Les entrées du journal sont stockées localement dans le navigateur via localStorage.

Mise à jour GitHub Pages :
1. Ouvrir le dépôt GitHub.
2. Remplacer index.html et sw.js par les fichiers de ce dossier.
3. Commit changes.
4. Attendre la publication GitHub Pages, puis ouvrir l'application sur l'iPhone.

Attention : le journal n'est pas synchronisé entre appareils. Les données restent dans le navigateur utilisé.

Mise à jour v11 : les vues de suivi mensuel et annuel ont été retirées. Le journal propose maintenant uniquement les compteurs par jour et par semaine.
